## 2. 能力详细需求

### 2.1 face-refine：文本捏脸（P0，阶段 1）

**用户故事**：玩家在捏脸工坊输入"大眼睛、瓜子脸、高鼻梁"，角色脸型立即按描述调整，并附一句中文说明。

**现状**：`walkstreet/src/creator/aiStylist.js` 前端直连大模型；apiKey 存 localStorage 明文暴露。

**验收标准**：
1. 网关提供 `face-refine` 能力：入参 `{ prompt: string, currentConfig: object }`，出参 `{ ok, reply, changes: {参数id: 数值}, source }`
2. 只修改 `changes` 中声明的参数，且被 `clampConfig` 约束在允许范围内
3. 前端调用走 `wsAiClient`（网关不可达时自动回退现有直连/本地规则引擎，功能不回退）
4. 网关侧 API Key 仅存在于服务端环境变量
5. 响应时间：模型调用失败时 3 秒内走回退逻辑
6. 输出为 JSON（`response_format: json_object`），模型返回非法 JSON 时降级不崩溃

**范围外**：多轮上下文记忆（阶段 2）、流式输出（捏脸是结构化 JSON，流式意义有限，留待通用对话能力）

### 2.2 image-avatar：以图生成（P1）

**用户故事**：玩家上传一张人脸照片，生成接近照片特征的捏脸参数。

**现状**：`walkstreet/src/creator/imageAvatar.js` 前端直连 vision 模型。

**验收标准**：
1. 迁移为网关能力，走 vision 模型路由（`isVisionModel` 判断逻辑移入网关）
2. 入参含 base64 图片，网关限制图片大小（≤ 5MB）
3. 前端回退策略同 face-refine

### 2.3 model-generate：AI 建模（P1，阶段 3）

**用户故事**：在 Model Studio 输入"一个红色电话亭"，几分钟后资产库出现可用的 GLB 资产，可直接在 3D 地图编辑器引用。

**需求要点**：
1. 长任务（分钟级）：必须走持久化工作流（Mastra Workflow），任务状态可查询、失败可重试
2. 外部生成服务（Meshy / Tripo / 混元3D，选型调研待办）：按次计费，必须走网关额度体系
3. 产物入库：glTF 减面/转换 → Model Studio 资产库（IndexedDB `assets` 表，见 `walkstreet/docs/model-studio-design.md`）
4. 人工审批：入库前用户确认预览

### 2.4 scene-build：AI 建场景（P1，阶段 3）

**用户故事**：在 3D 地图编辑器输入"在广场中间放个喷泉，周围加一圈长椅"，编辑器自动完成摆放并渲染预览。

**需求要点**：
1. Agent 工具循环：调用 editor3d 摆放/变换工具（坐标、旋转、缩放）
2. vision 自检迭代：截图 → 模型检查效果 → 再调整（多轮）
3. 人工审批：写入世界数据前用户确认（requireApproval）
4. 场景上下文：当前场景 JSON 作为输入（阶段 3 可用 Mastra Memory 增强"把喷泉再调高一点"类指令）

### 2.6 AI 栏附件（捏脸工坊输入框支持图片/模型文件，2026-11-17 上线）

**需求**：捏脸工坊底部 AI 输入栏（`#cc-ai-bar`）支持附带图片或 GLB 模型文件：
- **图片**（点击 ⊕ / 粘贴 / 拖入）：「AI 修改」走 `image-avatar` 能力（vision 模型），输入框文字作为补充要求；网关不可用时回退旧直连视觉模型/本地图像分析
- **GLB/GLTF 模型**（点击 ⊕ / 拖入）：「AI 修改」直接载入为自定义基础角色（非 AI 流程）；骨骼数决定精细/基础捏脸
- 保存：≤3MB 的自定义模型转 dataURL 持久化；过大仅本次会话有效（参数照常保存）

**验收**：
1. 附件芯片显示类型与文件名，可移除
2. 图片附件 + 网关（配 vision 模型）→ 返回照片特征参数并应用
3. 图片附件 + 网关挂 → 回退旧直连/本地分析，功能不劣于现状
4. GLB 附件 → 模型载入预览、可保存；重启后 dataURL 可重新加载
5. 非 image/模型文件、>20MB 文件被拒绝并提示

待前面能力沉淀后评估，先占位。

## 3. 非功能性需求（对所有 AI 能力生效）

| 类别 | 要求 |
|---|---|
| 安全 | API Key 仅存服务端；网关出网白名单；能力入参校验（zod schema） |
| 降级 | 任一 AI 能力失败不得阻塞业务主流程，前端必须有回退或明确错误提示 |
| 成本 | 网关记录每次调用的 token 用量与费用归属（能力 ID 维度），为额度/计费系统铺路 |
| 可观测 | 每次调用记录：能力 ID、耗时、模型、成功/失败、finishReason |
| 协议 | 网关对外暴露 OpenAI 兼容协议 + 能力化 REST（见设计文档），前端不感知框架 |
| 部署 | 独立 Node 进程（ai-gateway/），与 admin 并存；单机 PM2 多进程起步 |
