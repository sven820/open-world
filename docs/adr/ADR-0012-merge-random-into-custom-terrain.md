# ADR-0012：随机地形并入自定义地形（terrain.mode 收敛）

日期：2026-11-19 · 状态：已采纳 · 修正：[ADR-0003](ADR-0003-terrain-heightfield.md)（部分——模式枚举收敛，高度场架构不变）

## 背景

ADR-0003 引入高度场时设了三种地形模式：`random`（随机）/ `real`（真实）/ `custom`（笔刷雕刻）。实际使用中发现"随机地形"不是一个独立的最终状态——用户选随机生成后几乎总要继续用笔刷调整，而 `mode: "random"` 的高度场在笔刷入口（`terrainOnDown` 只认 `mode === "custom"`）处不可雕刻，模式切换还会整场重生成，两种能力被人为割裂。

同时发现多边形地图范围的编辑器分支不建地形主地面（只有道路走廊的路基补丁），黑色区域没有任何可变形网格，笔刷在界内非道路处雕不出形状。

## 决策

1. **`random` 模式退役，地形模式收敛为 `real` / `custom` 两值**：随机生成降级为
   custom 高度场的一种"填充手段"——`generateRandomTerrain` 输出 `mode: "custom"`
   并保留 `seed / amplitude / scale` 字段（面板回显与重新生成用），生成后立即可笔刷雕刻。
2. **旧地图零迁移兼容**：`ensureTerrain` 读到 `mode: "random"` 就地改写为
   `custom`（heights/seed 等原样保留），编辑器与运行时共用这一入口，旧随机地形
   打开即可继续雕刻；下次保存自然写回 `custom`，无需一次性迁移脚本。
3. **面板合并**：右侧 TERRAIN 面板去掉「随机地形高度」单选，随机参数
   （起伏幅度 / 起伏尺度 / 随机种子 / 随机生成按钮）并入「自定义地形高」区块；
   随机重生成时跨生成保留 `padFactor` 与 `maxGrade`。
4. **多边形范围的地形主地面**：`_rebuildAreaMeshes` 多边形分支在有地形时与矩形
   分支同样挂 8m 全局格点主地面（`buildGroundSurface` 新增 `clipPoly` 参数：
   顶点保持全集与路基补丁同相位，仅丢弃中心在多边形外的格子并截断索引），
   并取代深色底板（避免叠放 z-fight）；黑色区域由此获得可雕刻网格。
5. **自定义地形按基础高度锚定着色**：`_shadeTerrainPlate` 对 custom 模式以
   `terrain.baseHeight` 为基准色（t=0.85），抬升变亮、下压变暗，未雕刻的基础
   平地永远保持同一亮度；对比度随高差自适应（最小 60m 满量程）。修复两点：
   ① 原 `const span = hMx - hMn || 1` 的除零兜底把全平（span=0）强制变 1，
   平地仍走高度映射算出 t=0（最暗色）；② 旧逻辑按"最低点=最暗"归一化，
   抬升一次后最低点即基础平地本身 → 整片平地瞬间变暗。真实地形（real）保持
   旧的低点锚定（椭球高无"基础"语义，深谷=暗、山峰=亮更自然）。
   实测像素：抬升点 (0.374,0.441,0.522)=t1.0，远处平地 (0.331,0.392,0.465)=t0.85；
   屏幕像素平地(52,60,72) ≈ 随机(46~53,49~62,60~73)。
6. **超大地图地面降级**：`buildGroundSurface` 顶点超上限时自动放粗步距
   （8→16→…→512m）保住可见地形面（此前 >1.7 万米跨度直接返回 null，多边形
   分支连深色底板都被取代 → 整片区域隐形）；跨度 ≤1.7 万米从不触发，不影响
   ADR-0005 补丁同相位；主地面万一仍建不出时回退深色底板。
7. **地形基础高度（baseHeight）**：勾选「自定义地形高」即生成默认 **10m 的
   基础平地**（blankTerrain 填充 base，存 `terrain.baseHeight`）；面板新增
   「地形基础高度」滑杆（钳制 **-200~500m**，负值 = 盆地），编辑时按
   delta 整体平移 heights（保留已雕刻起伏），pads/走廊随新地形重算；
   随机生成的边缘回落目标也是基础高度（不再固定回落 0）。地形面挂
   斑驳地表纹理（`makeTerrainTexture`，与顶点高度着色相乘），全平基础
   地形也有「地表」质感，不再与无地形底板混淆。

## 被否决的备选

- **保留 `random` 模式 + 笔刷放行**：两处放行点（面板显隐 / 笔刷入口）逻辑分叉，
  且"随机"与"雕刻"在数据上本无区别，维持两值只是增加状态负担。
- **写一次性迁移脚本批量改旧地图**：localStorage 里的地图可能永不打开，
  惰性迁移（读时改写）覆盖面更全且零风险。

## 影响

- 地图 JSON：`terrain.mode` 取值收敛，旧值读时自动迁移，schema 不变（仍可选字段）。
- 无新增依赖；`buildGroundSurface` 新增可选参数向后兼容（运行时 city.js 调用不变）。
