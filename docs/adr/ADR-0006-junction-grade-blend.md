# ADR-0006：路口高程用「贴地引道」替代窄带回退

日期：2026-11-19 · 状态：已采纳
关联：修正 ADR-0004 的路口决策；继承 ADR-0003（单一高度权威）、ADR-0005（可见地面同精度）。

## 背景

用户实测：起伏地形（振幅 150m / 波长 500m）上只画**一横一纵两条路**，交叉口出现
三角形塌陷 / 断崖。

诊断（`temp-diag-junction.mjs` / `temp-diag-profile.mjs`）量化：

- 纵路在交点 design 高 ≈ **-62.5**，横路 ≈ **-79.7**，相差 **16m**；
- 沿纵路剖面 `z=-20: h=-56.9` → `z=-16: h=-78.9`，**一跳 22m（292% 坡）**；
- 交点处 base（原始地形）≈ -83.5，纵路 design 比 base 高 **20.4m**，横路只高 3.2m。

根因链条：

1. ADR-0004 的 `roadGradeAt` 在路口用 `wsum 1→1.6` 的**窄带**把高度强制回退到 base。
   `wsum` 在空间上只跨越十几米，回退幅度却达 20m+，必然形成断崖。
2. 尝试过把 `harmonizeJunctions` 改成"硬锚点 + 限坡传播"或"smoothstep 大窗口松弛"，
   均失败：纵路 design 是在陡降段被 `limitSlope` 抬高 20m 的产物，其自身剖面已用满
   35% 限坡预算，**没有余量再向横路拉 16m**；拉平后又会被限坡削回。
3. 因此"拉齐两条路的设计高程"这条路走不通 —— 被拉齐的对象本身就是失真的。

## 决策

**路口不去拉齐失真的 design，而是让两条路在交叉区域共同贴回 base（原始地形）；
贴地范围用按高差自适应的「引道半径」平滑过渡。**

1. **`buildRoadCorridors`** 末尾调用新增的 `detectJunctions(map, corridors, maxGrade)`：
   - 24m 空间格找含 ≥2 条走廊的格 → 取两路最近采样点对作为路口中心；
   - 引道半径 `r = clamp(路口附近 |design-base| 最大偏离 / maxGrade × 1.3,
     (两路半宽+过渡带之和)×1.2, 120m)`，`dev` 取路口前后 ±160m 内的最大偏离，
     乘 1.3 补偿 smoothstep 中心区 1.5× 的峰值斜率；
   - 结果写 `terrain.junctions`（派生数据，随地图 JSON 保存）。

2. **`roadGradeAt`** 移除旧的 `wsum 1→1.6` 回退：先算走廊设计高的加权平均 `graded`，
   若在任一路口引道内（`d < j.r`），按 `w = 1 - smoothstep(d/r)` 把 `graded` 混向
   `base`。交点 `w=1` 两路同读 base → 天然同高；引道边缘 `w=0` 回到各自设计高；
   中间连续。高差被摊到整个引道上，坡度受限、无断崖。

3. **`harmonizeJunctions`** 保持 ADR-0004 的四轮松弛（服务于相邻拼接路块接缝对齐），
   不再承担"把交叉点设计高程拉齐"的职责 —— 该职责交由路口贴地实现。

## 效果

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 路口沿路最大跳变 | 22m / 8m（292%） | 无断崖，剖面连续 |
| 路口处两路高差 | 16m | 0（同读 base） |
| `temp-test-road-grade.mjs` 路口坡度 | 30.60% | 20.67% |
| 路口核心区剖面 | 断崖 | 每 4m 变化 0.1~2.2m 平滑过渡 |

视觉验证：编辑器俯视 / 近景、游戏第三人称，十字路口平滑交汇，无三角塌陷。

## 被否决的备选

- **硬锚点 + 限坡传播**：路口钉死 target 后从两侧 clamp 相邻点。失败：纵路已用满
  限坡预算，锚点比邻点低 16m，传播后又被限坡削回，实测坡度反升至 133%。
- **smoothstep 大窗口松弛 design**：中心累积斜率超 35%，随后的 `limitSlope` 把拉平
  又削掉，锚点被吃。
- **加大回退带 wsum 阈值**：`wsum` 是权重不是距离，空间跨度由路宽决定（十几米），
  调阈值无法把 20m 高差摊到足够距离。
- **降低 maxGrade 让路贴地**：会把整条山地道路削成缓坡、变成悬空堤坝（ADR-0004 已否决）。

## 注意

引道内道路贴回 base，意味着路口段"随地形起伏"而非绝对水平 —— 这与用户"道路随
地形起伏、不要突然隆起/凹陷"的诉求一致。路口坡度等于该处自然地形坡度（陡地形上
可达 60%+，属原始地形而非道路造成）。
