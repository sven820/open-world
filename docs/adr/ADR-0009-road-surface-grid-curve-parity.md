# ADR-0009 路面采样与可见地面共用同一张 8m 格点曲面

日期：2026-11-19 · 状态：已采纳
关联：修正 ADR-0007 / ADR-0008（二者只缓解未根治）；沿用 ADR-0005 的 8m 同精度前提

> **后续修订（2026-11-19）**：本 ADR 只覆盖 `roadRibbon`/`stripGeometry` 的调用，
> 遗漏了拼接路 `rtTileQuadGeometry`（见 ADR-0010 横向细分）；且「lift 差 0.04m 足够」
> 的假设在三角面**内部**不成立 —— 8m 补丁面与 2m 路面面剖分不同，面内插值偏差可达
> 0.278m，见 ADR-0011 的三层余量修正。顶点 gap 恒 0.04m 只证明顶点一致，不代表面内一致。

## 背景

用户多轮反馈：3D 地图编辑器里道路（横路 / 纵路，程序化路网 1×2）路面仍有
**规则的浅蓝色菱形 / 三角斑块、锯齿缺口**，路口与路段边缘都有。此前三次修复
（ADR-0005 同精度、ADR-0007 横断面同相位、ADR-0008 深度偏置）均只缓解或无效。

## 根因（诊断量化）

用 `temp-diag-penetration.mjs` 对「补丁渲染面 − 路带渲染面」密集采样，结论明确：

| 地形振幅 | 补丁顶穿路带 | 最深 |
|---|---|---|
| 40m | 18.6% | +0.24m |
| 80m | 27.5% | +0.52m |
| 150m | 27.5% | +1.02m |

根因**不是**高度权威 `terrainHeightAt` 错了，而是**采样与剖分方式不同**：

- 主地面 `buildGroundSurface` / 路基补丁 `buildRoadBedGeometry` 是**全局 8m 格点**
  网格，顶点采样 `terrainHeightAt`，格点之间按三角 (a,c,b / b,c,d) 线性插值；
- 路面条带 `roadRibbon` / `stripGeometry` 是**沿中心线的条带网格**（横向 8m、纵向
  沿路 8m），相位与全局格点错开，也各自采样 `terrainHeightAt`；
- 两套**相位不同、剖分不同**的三角网格对同一个非线性高度函数做线性插值，得到的
  插值曲面必然互相穿插。补丁 lift 只比路带低 0.04m，插值误差在起伏处轻松超过
  0.04m → 补丁三角面从下方顶穿路面 → 规则菱形缺口。

这解释了为何此前修复无效：

- ADR-0005「同精度」只统一了主地面与补丁，没管路带这条独立网格；
- ADR-0007「横向 8m 细分」相位仍错开，只是缩小了误差；
- ADR-0008「polygonOffset + 不透明 + 写深度」只改深度不改几何，高度倒置 1m 时
  深度偏置无能为力（`temp-verify-ribbon.mjs` 当时因用 `transparent` 筛选路带，
  路带已改不透明 → 实际测到 0 条，验证是假阳性）。

抬高 lift 也压不干净：`temp-diag-fix-grid.mjs` 显示 lift 抬到 0.20m，振幅 150 时
纵路仍穿 12.7%。

## 决策

**让路面采样「可见地面实际渲染的那张曲面」，并细分足够密。**

1. `terrain.js` 新增 `gridHeightAt(map, x, z)`：按 8m 全局格点三角剖分
   (a,c,b / b,c,d) 对 `terrainHeightAt` 做线性插值，即主地面 / 补丁的渲染曲面高度。
2. 路面几何改采样 `gridHeightAt` 而非连续 `terrainHeightAt`：
   - `roadRibbon`（横路 / 纵路）：纵向沿路 + 横向均细分到 **2m**；
   - `stripGeometry`（描边路）：同样 2m 细分；
   - `fitGeometryToTerrain`（面路 / 拼接路块）：改采样 `gridHeightAt`。
3. 这样路面与补丁共用同一张曲面，路面恒高于补丁 0.04m（lift 差）；细分到 2m
   把路带三角内部的二阶插值误差压到 < 0.04m。

## 效果（诊断与实测）

- `temp-diag-grid2.mjs`：细分 8m→2m 后，穿插率
  - 振幅 40 / 80m：**0%**
  - 振幅 150m：0.34%、最深 +0.105m（极端地形残留，肉眼不可见）
- 浏览器几何实测 `temp-verify-ribbon.mjs`：36,018 个路带顶点相对补丁曲面的
  gap **恒为 0.04m**，异常 0。
- 视觉 `temp-visual-final.mjs`：用户同款场景（1×2 路网、at 非 8 倍数、起伏地形）
  俯视 / 斜视均路面完整连续、无菱形缺口；把补丁与主地面染纯红后，路面**不透红**，
  证明几何上已严格分离。
- `npm run build` + 4 项逻辑回归全部通过。

## 取舍与后续

- 2m 细分使路带顶点数从 ~4.5k 增到 ~36k（单条），仍远低于主地面 (26 万顶点)，
  性能可接受。
- ADR-0008 的 polygonOffset 保留（不透明 + 写深度仍用于交叉路带共面稳定），
  但不再是解决顶穿的手段；顶穿已由几何一致性根治。
- 交叉两条路带同高、同材质、同 offset，共面渲染稳定，无 z-fighting。
