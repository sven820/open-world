# ADR-0011 路面 / 补丁 / 主地面垂直分层余量（根治三角面内部顶穿）

日期：2026-11-19 · 状态：已采纳
关联：修正 ADR-0009 的「lift 差 0.04m 足够」假设；配合 ADR-0010

## 背景

ADR-0010 之后拼接路顶点已全部精确贴合 `gridHeightAt`，但放大截图仍见**大块锯齿缺口**
深入路面 1/3 宽。用户原始反馈的「锯齿 / 显示不全」主要来自这里。

## 根因（诊断量化）

`temp-measure-penetration.mjs` 在浏览器里对**渲染后的真实三角面**逐面测
「补丁面高度 − 路面面高度」（取三角面重心），结论：

| 指标 | 修复前 |
|---|---|
| 顶穿三角面 | 41 / 144（28.5%） |
| 最大顶穿 | 0.278m |
| 路面-补丁 lift 差 | 0.06m（不足） |

关键洞察：ADR-0009 让路面**顶点**采样 `gridHeightAt`（8m 格点渲染曲面），但路面是
**2m 三角网格**，补丁是 **8m 三角网格**。两者剖分线不同，三角面**内部**的线性插值
曲面不重合：补丁三角面（=精确 gridH）在路面 2m 三角面内部可能高出 0.278m。
lift 差 0.06m 远不够 —— 顶点层面一致不代表面内一致。

`temp-diag-subdiv.mjs` 验证：把路面细分到 0.5m 才能把面内偏差压到 0.055m，但顶点数
暴涨 ~10 倍，不可接受。

## 决策

**加大三层垂直余量，使路面相对补丁的高差 > 面内最大插值偏差（0.278m），
同时补丁仍高于主地面以填平壕沟。** 保持各层语义顺序（主地面 < 补丁 < 路面）。

| 层 | 旧值（相对 gridHeightAt） | 新值 | 说明 |
|---|---|---|---|
| 主地面（走廊内下沉） | −0.15 | **−0.42** | `ROAD_BED_DROP` 常量 |
| 路基补丁 lift | +0.04 | **−0.22**（编辑器）/ −0.23（游戏） | 高于主地面 0.19~0.20m |
| 横纵路 roadRibbon | +0.08 | **+0.14** | 路面-补丁 = 0.36m |
| 描边路 stripGeometry | +0.09 | **+0.16** | |
| 拼接路块 | +0.10 | **+0.15** | 比横纵路高 0.01m，交汇处不 z-fighting |
| 道路中心引导线 fatLine | +0.06 | **+0.18 / +0.20** | 高于新路面，否则被盖住 |

余量核算：路面(+0.14) − 补丁(−0.22) = 0.36m > 最大面内偏差 0.278m，余 0.082m；
补丁(−0.22) − 主地面(−0.42) = 0.20m 仍稳定填平壕沟。
三层间隔全部 ≥ 0.01m，消除交叉路带共面 z-fighting。

合成「路面相对补丁高 0.36m」在 8m/200m 尺度的地形上视觉不可见（路缘略高于路肩，
符合真实道路），换来的是面内顶穿彻底消除。

## 效果

- `temp-measure-penetration.mjs`：顶穿三角面 28.5% → **0%**，最大顶穿 0.278m → **−0.032m**
  （负值 = 路面恒高于补丁）。
- `verify-junction-zoom.png`：拼接路块锯齿 / 缺口完全消失，边缘平滑连续、标线连续。
- `verify-cross-zoom.png`：横纵路十字与拼接路三者交汇处颜色一致、无塌陷 / 斑块，
  标线可见。
- `npm run build` + 5 项逻辑回归（`temp-test-road-grade` / `terrain` / `pad` /
  `verify-final` / `verify-ribbon`）全部通过。

## 取舍与后续

- 路面整体上抬约 0.06m、下沉加深 0.27m 属渲染层偏移，不改变逻辑高度 `terrainHeightAt`，
  人物 / 车辆 / 物件贴地不受影响。
- 若未来地形振幅显著超过本测试（220m / 500m 尺度），需按 `temp-measure-penetration`
  重测余量并同步调整本表常量。四个 lift 分散在 `meshes.js` / `roadTiles.js` /
  `mapEditor3d.js` / `city.js`，建议后续提取为 `terrain.js` 导出常量集中管理。
