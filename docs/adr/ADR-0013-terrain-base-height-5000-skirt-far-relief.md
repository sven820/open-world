# ADR-0013：地形基础高度上限 5000m + 编辑器边缘裙边/视角适配 + 远景解析山地提前实现

日期：2026-11-20 · 状态：已采纳 · 修改：[ADR-0012](ADR-0012-merge-random-into-custom-terrain.md) 第 7 条（基础高度范围与控件形式）；提前部分实现 [terrain-optimization-plan](../plans/terrain-optimization-plan.md) 第 3 条

## 背景

基础高度是"整体平移高度场"的盆地/高原开关（ADR-0012 第 7 条），原设计钳制 **-200~500m**、滑杆调节。实际使用暴露三个问题：

1. **默认机位沉进地形**：编辑器默认机位 `(0, 140, 260)` 是按 ≤100m 量级地形设计的；基础高度 500m 时相机在地形面以下，打开编辑器只见黑屏，要手动缩小视角才能看到地图。
2. **地图边缘看不出海拔**：高度场网格只有"表面"没有"侧壁"，抬高后的地形板浮在 y=0 上方，从界外低角度看是一片薄板——500m 的高差完全不可感知，也违背"类比青藏高原、高处望远有纵深"的设计意图。
3. **500m 上限不够**：真实地理的高原（青藏高原平均 4000m+）无法表达；且运行时界外是死平的边缘延伸（`baseHeightAt` 出界钳制），站得再高也看不到远景山形——正是优化计划第 3 条「远景解析地形」要解决的问题。

## 决策

1. **基础高度范围 -200~5000m，控件改数字输入**（取代 ADR-0012 第 7 条的
   -200~500 滑杆）：5000m 量级对齐真实高原海拔；滑杆在 4700m 量程上无法
   精确取值，改 `type="number"` 步进 10m（回车/失焦提交，沿用 change 事件
   整体平移 heights、pads/走廊重算的原有语义）。负值盆地语义不变。
2. **编辑器地形边缘裙边（skirt，最终方案）**：矩形范围有地形时，沿**地图
   边界**一圈（与主地面同格距同对齐、边界顶点与主地面严丝合缝，主地面不再
   外扩 40m）铺垂直侧壁：顶环贴边界地形高度（与地形面齐平），底环 = 顶环
   高度 − 基础高度——设置基础高度 500，从地图边缘看就是一圈往下延伸 500m
   的裙边。材质用主题 `outer` 色；多边形范围主地面被裁剪、边界沿格线锯齿，
   裙边对不上会漏缝，故不铺（需求来自矩形大范围高原地图）。
   （修订记录：本条经历三轮返工——初版裙边围在边界外 40m 且固定落到 y=0；
   中间一版改为界外延续带 apron（边界外铺 400m 同海拔地面），用户复测否决；
   最终按用户描述定稿：顶贴地图边界、深度 = 基础高度。）
3. **视角自动适配**：新增 `_fitViewToTerrain`（按高度场包围盒把目标点与
   机位抬到地形之上，正南机位、距离取水平跨度与高差的大者）与
   `_fitViewIfNeeded`（仅当相机低于地形最高点 +30m 时拉起，平地/盆地不折腾）。
   触发点：打开编辑器、基础高度变更、随机重生成、真实高程采样、开启地形、
   罗盘复位视角。
4. **远景解析山地（计划第 3 条提前实现，纯几何方案）**：`baseHeightAt`
   出界分支接入 `farHeightOutside`——出界距离 260~2200m 间 smoothstep 渐入
   ridged 分形山地（固定种子，界外山形稳定），山体自边缘海拔起抬、幅度随
   边缘海拔放大（`240 + 0.55·边缘海拔`，钳制 280~6000m），边界处 relief=0
   与界内无缝。复用运行时 outer 环形板既有 32m 顶点 + `displaceGroup`
   位移，不动渲染层；界内主路径只多一个布尔判断，零性能开销。
5. **灰色基准面（y=0 基准的无限延伸视觉参考）**：只铺地图 bbox 外的四条
   环带（外沿 100km > 相机 far 50km，视觉无限延伸），不盖住地图范围——
   盆地图地形低于基准面，平面铺进去会从上方吞掉地形。顶点按曲率下沉
   （与 `_curveOffset` 同式）并整体 -0.6m 避让底板/裙边底缘：拉远时与弯曲
   基准依然贴合、杜绝共面闪烁；样式为透明网格画布（Canvas 贴图平铺，淡灰
   500m 暗格，与地图内 GridHelper 20m 亮格双重区分，不抢地形视觉）、
   不写深度；分段按尺寸自适应（顶点总量 ~2 万），重建带签名去重；
   卫星底图开启时隐藏（影像球面本身即基准参考，避免平面盖住影像）。

## 被否决的备选

- **界外延续带（apron，边界外铺 400m 同海拔地面）**：与运行时界外边缘延伸
  的数据语义一致，但用户复测明确否决——编辑器里边缘变成一片同海拔的平地，
  基础高度的落差完全不可见；用户要的是编辑器里边缘一圈 500m 高的裙边。
  已废弃（运行时界外延伸行为不受影响）。
- **计划原方案：远景纯 shader 位移（远景板不加顶点）**：现有环形板本就有
  32m 顶点且 `displaceGroup` 已按高度场顶起，纯几何实现零新增渲染管线，
  先兑现产品价值；shader 方案留作远景带加密/性能优化时的后续改造。
- **等计划第 2 条（高度缓存）做完再做远景**：出界点只有远景板位移（一次性）
  与界外动态实体贴地（量级小）采样，不构成热点；第 2 条落地后可白拿收益。
- **编辑器界外铺满整个远景环（3000m）**：编辑器重建频繁（每次笔刷收尾都
  重弯+重着色），铺满 3000m 环顶点量翻数倍；远景山形在运行时体验即可。

## 影响

- 地图 JSON：`terrain.baseHeight` 取值范围放宽（旧地图数值全部合法），schema 不变。
- `groundStepFor` 从 `buildGroundSurface` 抽出导出（裙边与主地面同格距），步距算法不变。
- 图层显隐：裙边归入「范围底板」层；裙边为独立不透明侧壁材质，不受「地形透明度」滑杆影响。
- 计划进度：第 3 条标记为提前实现（纯几何部分），shader 化与远景板改造仍未开始。
